# שבוע 1 — מאפס ללקוחה משלמת

המטרה: 1–2 לקוחות פיילוט סגורות (₪690/חודש) עד סוף השבוע.
העיקרון: כל יום יש משימה אחת מרכזית. לא מתפזרים.

## יום 1 (מוצ"ש/היום) — בונים את הדמו 🔨
- [ ] יצירת תת-חשבון "Meital Clinic Demo" (עם קלוד, צעד-צעד)
- [ ] פייפליין + שדות + יומן
- [ ] דף נחיתה בעברית (הקופי מוכן — הדבקה)
- [ ] בוט "נועה" (הפרומפט מוכן — הדבקה)
- [ ] אוטומציות W1–W3 לפחות (ליד חדש / אישור תור / תזכורות)
- [ ] בדיקה: ליאם שולח ליד לעצמו ועובר את כל המסלול בטלפון
- [ ] רשימת "מעגל חם": 5–10 אנשים שמכירים קוסמטיקאית (אמא, חברות, הספר)

## יום 2 (ראשון) — יורים 🚀
- [ ] בוקר: הודעה אישית לכל המעגל החם ("בניתי משהו, מכירה קוסמטיקאית
      שנמאס לה לפספס לקוחות? חודש ראשון חינם לשלוש הראשונות")
- [ ] 30 הודעות וואטסאפ מקובץ הפריוריטי (גרסה א', שם + פרט אישי)
- [ ] לרשום הכל בעמודות המעקב: נשלח / ענתה / דמו / נסגר
- [ ] כל מי שעונה → מטרה אחת: לקבוע דמו של 10 דקות ליום ב'-ג'

## יום 3 (שני) — ממשיכים + דמואים ראשונים
- [ ] 30 הודעות חדשות + פולו-אפ אחד לכל מי שלא ענתה מאתמול
- [ ] דמואים: היא שולחת ליד לדף הנחיתה מהטלפון שלה, חווה את הבוט,
      רואה את התור נכנס ביומן → הצעת פיילוט ₪690 → סגירה או מועד תשובה
- [ ] אחרי כל דמו: לרשום מה עבד ומה חרק (משפרים את התסריט)

## יום 4 (שלישי) — עוד 30 + סגירות
- [ ] 30 הודעות + פולו-אפים
- [ ] דמואים שנקבעו + מענה ל"תני לי לחשוב" ("מה היית צריכה לראות כדי להחליט?")

## יום 5 (רביעי) — סגירת השבוע
- [ ] פולו-אפ אחרון לכל הפתוחות
- [ ] מי שסגרה: תיאום הקמה + תשלום ראשון (ביט/העברה + חשבונית)
- [ ] סיכום עם קלוד: מספרים אמיתיים → מכוונים את שבוע 2

## המספרים שנעקוב אחריהם
| מדד | יעד שבוע 1 |
|---|---|
| הודעות שנשלחו | 120+ |
| תגובות | 15–25 |
| דמואים | 5–8 |
| פיילוטים סגורים | 1–2 ✅ |

## כללים לשבוע
1. הודעות = ידני, אישי, 20–30 ביום. לא יותר (חסימה), לא פחות (אין דלק).
2. כל שיחה מכוונת לדבר אחד: דמו. לא מוכרים בהודעות.
3. "לא" = דאטה, לא כישלון. רושמים וממשיכים.
4. נתקעת טכנית? צילום מסך לקלוד. לא מבזבזים שעה על לבד.
5. אין מודעות בתשלום השבוע. קודם הוכחות, אחר כך מדיה.
