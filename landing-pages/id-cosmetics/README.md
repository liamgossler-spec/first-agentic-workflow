# דף נחיתה – ID cosmetics (קרית מוצקין)

דף נחיתה חד-עמודי בעברית (RTL) לקליניקה לטיפוח העור, בנוי כקובץ HTML אחד ללא תלות בשום framework.

## צפייה
פותחים את `index.html` בדפדפן. הדף מותאם קודם כל למובייל (בר שיחה/וואטסאפ דביק בתחתית).

## תוכן
כל המידע בדף נלקח מהפרופיל העסקי בגוגל של העסק בלבד:
- שירותים: הסרת שיער בלייזר, טיפולי פנים ואנטי-אייג'ינג, הסרת נגעי עור ופיגמנטציה, פילינג עמוק, מזותרפיה, אפילציה, שעווה, קוסמטיקה רפואית
- טכנולוגיות: גלי רדיו, לייזר, אולטרה-סאונד, אלקטרו-קואגולציה, מיקרו-תרפיה
- דירוג גוגל: 4.8 · טלפון: 054-797-2721 · כתובת: שדרות משה גושן 14, קרית מוצקין

אין בדף ביקורות מומצאות, מחירים או שעות פעילות שלא אומתו.

## תמונות
התמונות נוצרו ב-Higgsfield (מודל Soul 2.0) וכרגע נטענות ישירות מה-CDN שלהם.
**לפני מסירת האתר ללקוחה** יש להריץ פעם אחת במחשב רגיל:

```bash
bash assets/localize-images.sh
```

זה מוריד את התמונות ל-`assets/img/` (כולל מקור PNG באיכות מלאה) ומעדכן את `index.html` לנתיבים מקומיים, כך שהאתר עצמאי לחלוטין.

## פריסה
קובץ אחד + תיקיית assets – אפשר להעלות לכל אחסון סטטי (Netlify / Vercel / cPanel / GitHub Pages).
