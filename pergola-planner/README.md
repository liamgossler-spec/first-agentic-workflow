# פרגו־פלאן · Pergola Planner

כלי ווב לתכנון וחישוב פרויקטים של פרגולות ומבני חוץ — בהשראת האפליקציה של NSF Outdoor Living, אבל גרסה עצמאית ופתוחה שאתה הבעלים המלא שלה.

הבנאי מזין מידות (ותמונה של השטח), והאפליקציה מחשבת אוטומטית כמות חומרים, רשימת חיתוך, שרטוט, אומדן עלות ותוכנית עבודה בשלבים.

## מה זה עושה

| יכולת | פירוט |
|-------|--------|
| 📐 קלט מידות | רוחב / עומק / גובה, סוג מבנה (פרגולה / סוכך / דק), חומר (עץ / אלומיניום / פלדה), סוג גג |
| 📷 תמונת שטח | צילום או העלאת תמונה (מוקטנת אוטומטית ונשמרת עם הפרויקט) |
| 📊 חישוב הנדסי | עמודים, קורות, רפפות, שכבת הצללה, יסודות בטון, ברזלים — לפי מפתחים ומרווחים |
| 📋 רשימת חומרים (BOM) | טבלת פריטים עם מפרט וכמויות |
| ✂️ רשימת חיתוך | אורכים וכמויות לכל אלמנט |
| 💰 אומדן עלות | מחירים ניתנים לעריכה, סכום כולל |
| 🗓️ תוכנית עבודה | שלבים עם תיאור ומשך זמן מוערך |
| 🖼️ שרטוט חי | מבט על + חתך צד (SVG) שמתעדכן בזמן אמת |
| 💾 שמירה | פרויקטים נשמרים בדפדפן (localStorage) |
| 🖨️ הדפסה / PDF | פריסת הדפסה נקייה של התוכנית |

## הפעלה

**הכי פשוט:** פותחים את `index.html` בדפדפן (דאבל-קליק). זהו — עובד גם בלי שרת.

**דרך שרת מקומי** (אם רוצים):
```bash
cd pergola-planner
npx serve .            # או:  python3 -m http.server 8000
```

## פריסה (Deploy) לאינטרנט

האפליקציה סטטית לחלוטין (HTML+CSS+JS, בלי build), אז אפשר לפרוס אותה בחינם כמעט בכל מקום:
- **Netlify / Vercel / Cloudflare Pages** — גוררים את התיקייה, וזהו.
- **GitHub Pages** — מפעילים Pages על התיקייה בענף.

## מבנה

```
pergola-planner/
├── index.html   # מבנה הדף (RTL, עברית)
├── styles.css   # עיצוב (פלטת outdoor-living, רספונסיבי, פריסת הדפסה)
├── app.js       # מנוע החישוב, שרטוט SVG, שמירה, אומדן
└── README.md
```

## התאמה אישית

- **מחירים** — ברירות מחדל ב־`app.js` תחת `PRICE`. אפשר גם לערוך בזמן אמת בכפתור "עריכת מחירים".
- **מפרטי חומרים** — `SPEC` ב־`app.js`.
- **לוגיקת חישוב** — הפונקציה `calc()` ב־`app.js` (מפתחים, מרווחים, נפח בטון וכו').
- **צבעים / מותג** — משתני CSS בראש `styles.css` (`--primary`, `--accent` וכו').

> ⚠️ האומדנים והחישובים הם לתכנון ראשוני בלבד. יש לאמת מול מהנדס/קבלן ותקנים מקומיים לפני ביצוע.
