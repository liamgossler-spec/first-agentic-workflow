# Workflows

Markdown SOPs that tell the agent *what* to do and *how*. Plain language, like
briefing a teammate. The agent reads the relevant workflow, then orchestrates
the `tools/` to carry it out.

Each workflow follows `_template.md`. Keep them current: when you learn a
constraint, a rate limit, or a better method, update the workflow (ask first
before overwriting, per CLAUDE.md).
