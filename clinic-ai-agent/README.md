# Aura — סוכנת קבלה חכמה לקליניקות יופי 💎

סוכנת AI שמדברת עם לקוחות בעברית, בטון חם ואנושי, עונה על שאלות (שירותים, מחירים, שעות), מסננת פניות ומובילה בעדינות לקביעת תור — כמו מזכירה אישית, רק שלא ישנה אף פעם.

**גרסה זו (שלב 1):** הרצה מקומית על המחשב שלך, עם ממשק צ'אט בדפדפן שמדמה וואטסאפ (או דרך הטרמינל). בלי חיבור לוואטסאפ עדיין — רק כדי לוודא שהסוכנת עובדת ונשמעת מושלם. החיבור לוואטסאפ מוכן כתשתית לשלב הבא (ראו בתחתית).

---

## מה צריך כדי להתחיל

- **Node.js** גרסה 18 ומעלה ([הורדה](https://nodejs.org)). לבדיקה: `node -v`
- **מפתח Anthropic API** — נרשמים ומקבלים בכתובת <https://console.anthropic.com/>

## התקנה והרצה — שלב אחר שלב

### 1. התקנת התלויות
מתוך תיקיית הפרויקט (`clinic-ai-agent`), הריצו בטרמינל:

```bash
npm install
```

### 2. הכנסת מפתח ה-API
צרו קובץ בשם `.env` (אפשר פשוט להעתיק את הקובץ לדוגמה):

```bash
cp .env.example .env
```

פתחו את `.env` והכניסו את המפתח שלכם אחרי הסימן `=`:

```
ANTHROPIC_API_KEY=sk-ant-...המפתח-שלכם...
```

> 🔒 המפתח נשמר **רק** בקובץ `.env` המקומי. הוא לא נמצא בקוד ולא עולה ל-git (הקובץ ב-`.gitignore`).

### 3. הרצה

```bash
npm start
```

ייפתח השרת ותראו בטרמינל את הכתובות. פתחו בדפדפן:

- **דף הנחיתה:** <http://localhost:3000/>
- **צ'אט הדמו:** <http://localhost:3000/chat>
- **דשבורד ניהול (CRM):** <http://localhost:3000/admin>

זהו — אפשר לשוחח עם הסוכנת בדפדפן, ולראות את השיחות והתורים בדשבורד. ✨

### חלופה: צ'אט בטרמינל (בלי דפדפן)

```bash
npm run cli
```

לסיום השיחה: הקלידו `יציאה` או `Ctrl+C`.

## שימוש חוזר בין לקוחות — לקוח חדש = רק קובץ הגדרות חדש

כל הפרטים הספציפיים של הקליניקה חיים בקובץ אחד: **`clinic-config.json`**. ה-system prompt נבנה ממנו אוטומטית. כדי להקים סוכנת ללקוח חדש — מעדכנים רק את הקובץ הזה, **בלי לגעת בקוד**.

מבנה הקובץ:

```jsonc
{
  "businessName": "הקליניקה של מאיה",          // שם העסק
  "tagline": "המקום שלך להרגיש ולהיראות במיטבך",
  "assistantName": "נועה",                      // שם הסוכנת
  "tone": "חם, אישי, נינוח ומפנק…",             // טון הדיבור
  "services": [                                  // רשימת שירותים
    { "name": "טיפול פנים מקצועי", "price": "₪350", "duration": "60 דק'", "description": "…" }
  ],
  "hours": {                                     // שעות פעילות
    "ראשון–חמישי": "09:00–19:00",
    "שישי": "09:00–14:00",
    "שבת": "סגור"
  },
  "availableSlots": [                            // שעות פנויות לדוגמה שהסוכנת תציע
    "יום ראשון, 10:00",
    "יום שלישי, 12:00"
  ],
  "location": "רחוב דיזנגוף 120, תל אביב",
  "phone": "03-1234567",
  "policies": "ביטול תור עד 24 שעות מראש…"
}
```

רוצים לנהל כמה לקוחות בו-זמנית? אפשר להצביע על קובץ הגדרות אחר דרך משתנה סביבה:

```bash
CLINIC_CONFIG_PATH=./clinics/dana.json npm start
```

> את **אישיות** הסוכנת (הניסוח בעברית) אפשר לכוונן בקובץ `src/system-prompt.he.txt`. הפרטים (מחירים/שעות וכו') מגיעים תמיד מהקונפיג דרך פלייסהולדרים בפורמט `{{...}}`.

## איך זה בנוי

```
clinic-ai-agent/
├── clinic-config.json        ← כל הפרטים של הקליניקה (לקוח חדש = עורכים כאן)
├── .env                      ← מפתח ה-API (מקומי, לא עולה ל-git)
├── .env.example              ← תבנית למפתח
├── package.json
├── src/
│   ├── server.js             ← שרת + API + מנוע הסוכן (generateReply) + הערת חיבור WhatsApp
│   ├── cli.js                ← צ'אט בטרמינל
│   ├── config.js             ← טעינת ההגדרות
│   ├── systemPrompt.js       ← בניית ה-system prompt דינמית מהקונפיג
│   └── system-prompt.he.txt  ← תבנית אישיות הסוכנת (עברית, עם {{placeholders}})
└── public/
    ├── landing.html          ← דף נחיתה שיווקי
    └── index.html            ← ממשק צ'אט בסגנון וואטסאפ
```

**עקרונות מפתח:**
- **מודל:** `claude-sonnet-4-6` (Anthropic). ניתן לשינוי ב-`src/server.js` / `src/cli.js`.
- **זיכרון שיחה:** ה-API חסר-מצב, ולכן הלקוח שולח את **כל היסטוריית השיחה** בכל קריאה — כך הסוכנת זוכרת הכל ולא חוזרת על עצמה.
- **אבטחה:** המפתח נטען מ-`.env` בלבד, אף פעם לא בקוד.

## שלב 2 — חיבור לוואטסאפ (עדיין לא ממומש)

הקרקע מוכנה. מנוע הסוכן עטוף בפונקציה אחת — `generateReply(history)` ב-`src/server.js` — שאפשר לקרוא לה גם מ-webhook של וואטסאפ. בתחתית `src/server.js` יש בלוק הערות מפורט שמראה בדיוק איפה ואיך יתחבר ה-webhook דרך ספק רשמי (**Twilio / 360dialog / Meta Cloud API**): אימות ה-webhook, קבלת הודעה נכנסת, קריאה ל-`generateReply`, ושליחת התשובה חזרה.

מה יתווסף בשלב 2:
- אחסון שיחות מתמשך (DB) במקום זיכרון בדפדפן.
- אימות חתימת ה-webhook של הספק.
- מתאם לספק שנבחר (קבלה/שליחה של הודעות).

## הארכיטקטורה — כל המודל

```
ערוצים (וואטסאפ / אינסטגרם / צ'אט באתר)
        │
        ▼
   סוכן AI עם כלים (Tool Use)
   check_availability · book_appointment · update_contact · escalate_to_human
        │
        ▼
   שכבת CRM  ──►  ספק:  local (מאגר מקומי)  או  Altegio (alteg.io)
        │
        ▼
   דשבורד /admin  ── שיחות · תורים · לקוחות · סטטיסטיקות
```

- **שיחות / אינבוקס** נשמרים תמיד אצלנו (זה לא מה ש-Altegio מנהל).
- **זמינות + תורים + לקוחות:** ב-`local` — מאגר מקומי; ב-`altegio` — היומן האמיתי של הקליניקה.
- מעבר ל-Altegio = הגדרת `CRM_PROVIDER=altegio` + טוקנים ב-`.env` (ראו `.env.example`) — **בלי שינוי קוד**.

> מתאם ה-Altegio (`src/altegio.js`) הוא **סקלד אינטגרציה**: יש לאמת endpoints וטוקנים מול חשבון Altegio אמיתי לפני שימוש בפרודקשן.

**קבצים מרכזיים:**
- `src/agent.js` — הסוכן והכלים (Tool Use).
- `src/crm.js` — שכבת ה-CRM (בוחרת ספק).
- `src/altegio.js` — מתאם Altegio.
- `src/store.js` — מאגר מקומי מתמשך.
- `src/server.js` — שרת, API, ונקודת חיבור WhatsApp לשלב 2.
- `public/admin.html` — דשבורד הניהול.
