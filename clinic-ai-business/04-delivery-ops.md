# 04 — אספקה, תפעול וסטאק טכנולוגי

## 1. הסטאק הטכנולוגי (איך באמת בונים את זה)

המטרה: רזה, מהיר להקמה, וזול לתפעול. שתי דרכים:

### מסלול A — No/Low-Code (מומלץ להתחלה)
- **המוח (AI):** Claude API (Anthropic) — מודל `claude-haiku-4-5` למענה זול ומהיר, או
  `claude-sonnet-4-6` לשיחות מורכבות. מחיר לשיחה: סנטים בודדים.
- **וואטסאפ:** חיבור רשמי דרך **360dialog** או דרך **GreenAPI** (פשוט וזול לישראל),
  או WhatsApp Cloud API של Meta.
- **אורקסטרציה/לוגיקה:** **Make.com** או **n8n** (אפשר self-host) — מחבר וואטסאפ ↔ Claude
  ↔ יומן/גיליון.
- **אינסטגרם DM:** **ManyChat** (תומך IG + WhatsApp) — מצוין להתחלה מהירה.
- **תיאום תורים:** היומן הקיים של הקליניקה, או Calendly / Google Calendar.
- **CRM/לידים:** Google Sheets / Airtable להתחלה.

### מסלול B — Custom (כשתגדל)
- שרת Node/Python שמריץ את הלוגיקה, Claude API, WhatsApp Cloud API ישיר, DB אמיתי.
- מאפשר שליטה מלאה, מיתוג, ותמחור גבוה יותר. עובר לכאן אחרי 5-10 לקוחות.

> 💡 אפשר לממש את מסלול B בתוך מסגרת ה-WAT הזו: `workflows/clinic_bot.md` שמגדיר את הלוגיקה
> ו-`tools/` עם סקריפטים (שליחת וואטסאפ, קריאה ל-Claude, כתיבה ליומן). תגיד לי ואתחיל לבנות.

### עלויות תפעול משוערות ללקוח/חודש
| רכיב | עלות |
|------|------|
| Claude API | ₪50-150 (לפי נפח) |
| WhatsApp (360dialog/GreenAPI) | ₪50-150 |
| Make/n8n/ManyChat | ₪50-100 (מתחלק בין לקוחות) |
| **סה"כ** | **≈ ₪150-400** → מול ריטיינר ₪1,500-4,000 = שוליים 80%+ |

## 2. טופס אונבורדינג (מה לאסוף מהלקוח)

שלח ללקוח טופס/שאלון שממלא תוך 20 דק':
1. שם הקליניקה + שם העוזרת הדיגיטלית (אם רוצה שם).
2. כתובת, חניה, שעות פעילות.
3. רשימת כל הטיפולים + מחירים/חבילות מדויקים.
4. 15-20 שאלות נפוצות שהלקוחות שואלים + התשובות.
5. טון מותג (רשמי/חברי/יוקרתי) + 3 הודעות לדוגמה שהיא ענתה בעצמה (ללמוד את הסגנון).
6. מה **אסור** לבוט לענות עליו (רפואי, מקרים מיוחדים).
7. למי להעביר מקרים מורכבים (טלפון/וואטסאפ של הבעלים/מטפלת).
8. גישה: מספר וואטסאפ עסקי + חיבור יומן/גיליון.

## 3. תהליך אספקה (Fulfillment SOP) — 3-5 ימי עבודה

| יום | פעולה |
|-----|-------|
| 1 | שיחת אונבורדינג + מילוי הטופס + קבלת גישות |
| 2 | בניית ה-System Prompt המותאם (מתבנית `02`) + הזנת מחירון/טיפולים |
| 3 | חיבור וואטסאפ + יומן/גיליון + בדיקות פנימיות (20+ תרחישי שיחה) |
| 4 | בדיקת קבלה עם הלקוח (היא בודקת בעצמה) + תיקונים + הדרכה קצרה |
| 5 | Go-Live 🚀 + מעקב צמוד 48 שעות ראשונות |

## 4. מה כלול בריטיינר החודשי (ההצדקה למחיר)

הריטיינר הוא **שירות**, לא רק "תחזוקה". מה שמספק ערך חודשי מתמשך:
- **עדכונים שוטפים:** מחירים, טיפולים חדשים, מבצעים, שעות חגים.
- **אופטימיזציה:** קריאת שיחות אמת, זיהוי איפה הבוט מאבד אנשים, שיפור הניסוחים.
- **דוח ביצועים חודשי:** כמה פניות נענו, כמה תורים נקבעו, שעות שיא, אחוז סינון.
- **תמיכה:** ערוץ ישיר לבעלים. את ה"איש AI" שלה.
- **שיפורים (Growth/Scale):** A/B על הודעות פתיחה, הוספת Follow-up/Upsell, אינטגרציות חדשות.

> שלח דוח חודשי יפה — זה מה שגורם ללקוח להמשיך לשלם ולא לבטל.

## 5. סיכונים והתמודדות

| סיכון | מה עושים |
|-------|----------|
| חסימת WhatsApp (API לא רשמי) | השתמש ב-API רשמי (360dialog/Cloud API) ללקוחות בתשלום |
| הבוט נותן מידע שגוי | Guardrails ב-System Prompt + "בספק תעביר לאדם" + בדיקת קבלה לפני Go-Live |
| לקוח רוצה לבטל ריטיינר | דוח ערך חודשי + תוצאות מדידות + חוזה 3 חודשים מינ' |
| תלות בפלטפורמה (ManyChat וכו') | תעד הכל; כשתגדל עבור למסלול Custom (מסלול B) |
| פרטיות/רגולציה | אל תאחסן מידע רפואי; הצהרת פרטיות; אישור הלקוחה לאיסוף טלפון |

## 6. חוזה / הצעת מחיר (מבנה בסיסי)

- **תיאור השירות:** הקמת עוזרת AI + ליווי חודשי.
- **תשלום:** הקמה מראש (או 50/50), ריטיינר חודשי בהוראת קבע, **התחייבות 3 חודשים מינ'**.
- **כלול בהקמה:** הגדרה, התאמה, חיבורים, הדרכה, 14 יום ליווי צמוד.
- **כלול בריטיינר:** לפי החבילה (Care/Growth/Scale).
- **בעלות:** ה-System Prompt וההגדרות שייכים לך; הלקוח מקבל רישיון שימוש כל עוד הריטיינר פעיל.
- **לא כלול:** עלויות צד ג' (אם גובים בנפרד) / פיתוחים מותאמים מעבר להגדרה.
