# אתר ZYNX — דף נחיתה אינטראקטיבי

דף נחיתה שבו בעלת קליניקה **מתנסה בבוט בעצמה** (דמו חי) ו**משאירה פרטים** שנופלים ישר
לוואטסאפ שלך. קובץ אחד עצמאי — נפתח ועובד בכל מקום.

## מצב ברירת מחדל = הדגמה מלאה (מוכן עכשיו, בלי כלום)
- הדמו בדף רץ כ**סימולציה בדפדפן** (עברית, עם כפתורי-קיצור). אין צורך בשרת.
- הטופס מציג **אישור "נשלח בהצלחה"** יפה עם הפרטים — בלי צורך במספר וואטסאפ. מושלם להראות ללקוחות כהדגמה.

## מה קורה כשלקוחה לוחצת "שלחי לי דמו"?
לפי ההגדרות בקובץ `index.html` (ב-`<script>`), לפי סדר עדיפות:

1. **מצב הדגמה (ברירת מחדל):** מוצג אישור יפה + הליד נשמר בדפדפן בלבד. (לא מגיע אלייך — להדגמה בלבד.)
2. **`FORM_KEY` מוגדר → הליד נשלח למייל שלך מיד** (דרך Web3Forms, חינם, בלי שרת). **מומלץ.**
3. **`WA_NUMBER` מוגדר →** נפתחת גם שיחת וואטסאפ עם פרטי הליד מוכנים.
4. **`ZYNX_API` מוגדר →** הליד נשמר גם בשרת/CRM שלך.

### להפעיל קבלת לידים למייל (30 שניות, חינם)
1. כנסי ל-**web3forms.com**, הזיני את המייל שלך → תקבלי **Access Key**.
2. בקובץ `index.html`, בשורת `const FORM_KEY = "";` — הדביקי את המפתח בין הגרשיים.
3. זהו. מעכשיו כל מי שממלא את הטופס — הפרטים נוחתים במייל שלך תוך שניות.

## הגדרות (בקובץ `index.html`, ב-`<script>`)
```js
const WA_NUMBER = "";   // אופציונלי: מספר וואטסאפ — הליד פותח שיחה איתך
const FORM_KEY  = "";   // ★ Access Key מ-web3forms.com → ליד למייל שלך (מומלץ)
const ZYNX_API  = "";   // אופציונלי: שרת לדמו AI אמיתי + שמירת לידים/CRM
```

## איך מעלים לאוויר (חינם)
- **הכי קל — Netlify Drop:** היכנסי ל-app.netlify.com/drop, גררי את תיקיית `site/`. תוך 10 שניות יש כתובת חיה.
- **GitHub Pages:** Settings → Pages → בחרי את הברנץ' והתיקייה `clinic-ai-business/site`.
- **דומיין משלך:** העלי את `index.html` לאחסון/דומיין שלך.

## שדרוג לדמו AI אמיתי (אופציונלי)
במקום הסימולציה — הבוט עונה עם Claude אמיתי (עונה לכל שאלה, לא רק תסריט):
1. הריצי את השרת: `pip install flask anthropic` + `ANTHROPIC_API_KEY` ב-`.env` →
   `python tools/demo_server.py`
2. פרסי אותו (Render/Railway/Fly — חינם) וקבלי כתובת.
3. הכניסי את הכתובת ל-`ZYNX_API` בקובץ. זהו — הדמו עכשיו על AI אמיתי, והלידים נשמרים גם בשרת.

## בדיקה
`python tools/demo_server.py --selftest` — מאמת שהדף, הדמו ולכידת הלידים עובדים (בלי רשת).
