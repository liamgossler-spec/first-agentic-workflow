# 🤖 בלוטפרינט עסק: סוכני AI לקוסמטיקאיות וקליניקות אסתטיקה בישראל

הסט הזה הוא ה"קופסה" המלאה להקמת עסק שמוכר סוכני צ'אט חכמים (AI) לקליניקות אסתטיקה
וקוסמטיקאיות בישראל — תחום עם LTV גבוה ללקוח, הרבה לידים שנופלים, ובעלים שמבינים ROI.
המטרה: **הקמה גבוהה (one-time) + ריטיינר חודשי גבוה**.

## מה יש כאן

| קובץ | מה זה נותן לך |
|------|----------------|
| `01-blueprint.md` | המודל העסקי המלא: מי הלקוח, מיצוב, יתרון תחרותי, מודל פיננסי, ותוכנית 90 יום |
| `02-product-and-bot.md` | מה הבוט עושה בפועל + ה-System Prompt האמיתי בעברית + תרחישי שיחה לדמו |
| `03-sales-kit.md` | סקריפטים ל-DM/וואטסאפ, שיחת מכירה, טיפול בהתנגדויות, סקריפט Loom |
| `04-delivery-ops.md` | תהליך אונבורדינג ואספקה, סטאק טכנולוגי, ומה כלול בריטיינר החודשי |

## איך מתחילים (סדר פעולות מהיר)

1. קרא את `01-blueprint.md` — תבין את המודל ותחליט על החבילות.
2. הקם את **בוט הדמו** מתוך `02-product-and-bot.md` (System Prompt מוכן).
3. בנה רשימת 50 קליניקות (לפי `03-sales-kit.md`).
4. שלח Outreach לפי הסקריפטים → קבע 5 שיחות מכירה.
5. סגור 3 לקוחות ראשונים במחיר Founders → צבור case studies → העלה מחיר.

> ⚠️ הערה: אלה חומרי אסטרטגיה ותוכן — לא קוד פרודקשן. הבוט עצמו (System Prompt + Flows)
> מוכן לשימוש ואפשר להריץ אותו על Claude API + WhatsApp. פרטי הסטאק ב-`04-delivery-ops.md`.
